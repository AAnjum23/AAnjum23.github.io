# Amena Anjum — academic portfolio

A lightweight, static academic portfolio for GitHub Pages.

## Files

- `index.html` — page content and semantic structure
- `styles.css` — responsive styling and light/dark themes
- `script.js` — small theme toggle and current-year label
- `Amena_Anjum_CV_Public.pdf` — public CV copy

The site uses no framework or build step. GitHub Pages serves the repository root from the `main` branch.

## Updating content

Edit the corresponding section in `index.html`. Update links there when adding public documents. Keep private contact identifiers and referee details out of public files.
